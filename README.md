# OrgAssets Live Demo

This repository hosts a public static demo of OrgAssets on GitHub Pages.

OrgAssets is a browser-based demo portal for mapping people, systems/assets, owners, assignments, renewals, spend, cleanup actions, reports, imports, users, and branded PDF exports.

## Demo Notes

- Data is stored in the browser using localStorage for demo purposes.
- The GitHub Pages version is static/browser-only. Folder Backup ZIP is available only in local server installs.
- Do not enter real passwords, API keys, MFA seeds, recovery codes, private keys, or credential notes.
